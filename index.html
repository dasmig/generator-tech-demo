C++23 header-only libraries compiled to WebAssembly with Emscripten. Everything runs in your browser — no server required. Try personality traits and Big Five scores.

⭐ Persona Generator

Generates a complete fictional persona with persona-generator, which composes eight libraries through entity-generator fields: country, city, birthday, body, name, personality, religion, hobbies, favourite genres and occupation in one call. Each field is conditioned on the ones it depends on (the country sets the city, the name culture, the body and the job; the age and sex set the rest), and the persona's seed replays all of it. This is fictional sample data, not a description or prediction of a real person.

occupation-generator

Generate a fictional employment status, education level and job from country, sex and age inputs, using ILO labour force statistics. Compare the four education levels while holding the country, sex and seed fixed. Outputs are synthetic, not predictions about individuals or groups. GitHub →

Comparison fixes age 35 and an employed status, and varies only the education input. “Any” country and sex are resolved once. Under 15 a person is always a student with no job. Status and education come from measured rates (139 and 185 surveyed countries; others use a regional mean); the job catalogue is curated. Results can coincide.

phone-generator

Generate fictional phone numbers that are valid in a country's numbering plan, drawn from libphonenumber's mobile and fixed-line ranges and written the way the country writes them. The safe option uses the numbers regulators reserve for fiction (for example 555-01xx in the US and Canada) where a country has such a range; elsewhere it avoids the allocated ranges. Outputs are synthetic. GitHub →

“Any” country is drawn by population. Compare safe draws one call seed and shows the number with and without the safe option; the type may differ when the country has a reserved range for only one type. “Reserved for fiction” is Yes only for numbers from a regulator's range.

email-generator

Generate fictional email addresses in a country's style from a name, nickname and birth year, with the providers people use there. Leave the names empty for a handle. Compare the same name and seed across eight countries. The safe option uses the reserved example domains. Outputs are synthetic. GitHub →

Names are folded to ASCII (Ø is o) and family-name particles are skipped (da Silva is silva). A style is only used when the inputs can fill it: no birth year, no year in the address. “Any” country is drawn by population. Comparison uses the same call seed in US, DE, BR, JP, CN, RU, FR and EG.

trait-generator

Generate fictional personality traits and resolved Big Five scores. Scores are centered on zero before trait effects, not percentages or a personality assessment. GitHub →

Use 1–16 digits (0–9, a–f), without 0x. Replay with the output seed and the same trait count.

Each score starts with a normal draw (mean 0, standard deviation 1) and adds the selected traits' catalogue loadings. Base values also influence trait selection; exclusive groups, conflicts and synergies constrain the draw. These are unbounded model values, not measured traits or percentiles.

city-generator

Sample cities from the embedded GeoNames lite catalogue. Compare population-weighted and uniform selection within the same country filter. GitHub →

Single draw is population-weighted. Batches draw with replacement: repeated cities count again. Each pair uses the same random seed. Uniform gives every eligible catalogue row equal probability; weighted uses max(population, 1). Observed shares fluctuate and cover the lite catalogue, not every city or resident.
